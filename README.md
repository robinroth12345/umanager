# umanager

Lehrerpult (Noten, Sitzpläne, Stundenplan, Stoffpläne, Sync) zusammen mit dem Modul **Planung** (Jahresübersicht, Stoffverteilung mit Bildungsplan, Kalender).

- Code: Einzeldatei-App `index.html` mit Offline-Hülle (`sw.js`, `manifest.webmanifest`).
- Schülerdaten gehören nie in dieses Repo. Sie liegen nur im Speicher der Geräte beziehungsweise im verschlüsselten Sync von Lehrerpult.
- Plandaten (ohne Schülerdaten) liegen als JSON im Repo.

Ausgangsstand: Lehrerpult-Code aus `HTML-Apps/Lehrerpult` (Stand 2026-10-19).
